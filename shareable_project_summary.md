## Quick Share Version

AgroVerse includes four ML-focused modules in the document:

1. Disease Detection using the PlantVillage dataset with 54,306 images and a CNN model.
2. Crop Recommendation using the Crop Recommendation Dataset with 2,200 records and a Random Forest model.
3. Soil Productivity using FAO Soil Health Data with 1,800 records and a Linear Regression model.
4. Price Prediction using the Agmarknet Commodity Dataset with 3,500 records and a Naive Bayes model.

In the current project code, the main modules available are Disease Detection, Crop Recommendation, Soil Prediction, Market/Price Forecasting, Weather, Government Schemes, Community Forum, Farm Log, and User/Auth features.
